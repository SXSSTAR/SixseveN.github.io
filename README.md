# SixseveN — GitHub version

Première reconstruction statique du site Wix SixseveN.

## Mise en ligne sur GitHub Pages

1. Créer un dépôt GitHub, par exemple `sixseven`.
2. Décompresser ce dossier dans le dépôt.
3. Envoyer `index.html`, `css/`, `js/` et `assets/`.
4. GitHub → Settings → Pages → Deploy from branch → `main` / root.
5. Le site sera disponible à l'adresse GitHub Pages du dépôt.
